# School rubric checklist — 25 points maximum

This is a requirements checklist, not a predicted or guaranteed score.

## Content & Creativity — 7 points
- [x] Three posts use the supplied facts and include concrete details about routine, Ada Payment, PhotoForge, Asepriid, and interests.
- [x] The digital-life post explains AI as a development aid and credits Azizjon for designing and configuring the system.
- [x] A reflection connects creativity, learning, and the process of making digital projects.
- [x] Local SVG illustrations are art-directed to match the content.

## Communicative Language — 7 points
- [x] Main website content is written in English with a school-appropriate, personal tone.
- [x] Sentences use clear connections and varied structures without inventing personal stories.
- [x] The default three-post body copy is kept separate from labels, About Me, comments, and navigation in the word-count document.

## Blog Design & Organisation — 6 points
- [x] Clear hero, featured post cards, article sections, About Me, conversation area, reflection, and footer.
- [x] Each post has a visual treatment, heading hierarchy, caption/metadata, and readable text area.
- [x] Responsive CSS for desktop, tablet, and mobile.
- [x] Actual ASSAN TTF assets are referenced through local `@font-face` declarations; fallbacks are included.

## Reflection & Audience Engagement — 5 points
- [x] A prominent audience question asks what app a reader would create.
- [x] Exactly two fictional example comments are shown, and each has an author reply.
- [x] Fictional examples are explicitly labelled.
- [x] A grounded reflection section is included.

## Word count convention
- Assignment Version: target 180–250 English words across the three post bodies only.
- Extended Version: separate document section, approximately 350–400 English words across the three post bodies only.
- Excluded from both totals: titles, labels, captions, navigation, About Me, question, fictional comments, replies, and reflection.
